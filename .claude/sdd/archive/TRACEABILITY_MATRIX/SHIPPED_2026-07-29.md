## Lessons Learned

### Process

- Cross-adopter configurations the home repo never exercises are a review blind spot by construction: the Important finding (traceability-only consumers getting TM findings) was invisible to every test because this repo always ships both blocks together — distributed-plugin features need adversarial probes for each block-combination a consumer can legally hold.
- A mid-build defect caught by the implementing specialist (template heading vs exact slug) beats one caught at review: encoding the lesson (exact slugs) into the implementing agent's brief made it check.

### Technical

- Explicit configuration flags beat inference from empty vocabularies — inferring "not configured" from empty lists was exactly the I1 bug; a boolean carries intent.
- Literal template placeholders can satisfy substring checks ("{Pass / Fail}" contains "pass") — coverage gates must fail closed on brace placeholders, not skip them.

### Communication

- The filled matrix doubles as the PR evidence table — Increment 8 gets its readiness surface for free.
