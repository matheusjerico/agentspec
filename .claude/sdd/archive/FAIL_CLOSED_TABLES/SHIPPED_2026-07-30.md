## Summary

Tables stopped being nine hand-rolled regexes and became one structural parser. `spec_linter/markdown` returns `ParsedTable`/`ParsedRow`/`TableError` under a single invariant — every recognised table line becomes a row, an error, or both — so "malformed" can no longer be mistaken for "absent". Both phase contracts consume it (a grep test enforces that no row regex or cell split survives), one escape-aware splitter replaced seven copies that all broke on an escaped pipe, and the parser is total: twelve hostile inputs yield errors, never a stack trace. All five bypasses PR A deferred are closed in both their duplicated and moved variants, plus three more the review found. PR B of the remediation program; unblocks E and F.

## Lessons Learned

### Process

- Three rounds, three distinct Criticals, none a repeat — but the marginal value fell while the cost held. The maintainer named it: the review was framed as "attack Markdown grammar", an unbounded surface. Reviews should target what the artifact is FOR — silent pass, cry-wolf, regression, promised capability — not an open grammar.
- Round 3's finding was that round 2's fix landed in one of six call sites. Fixing a class means grepping the class, not the reported instance.
- The gate rejected this PR's own report twice: once for a literal escaped pipe written in prose (the feature detecting its author), once for an Important finding deferred without the contract's resolution grammar. The second was resolved by reclassifying to the severity the reviewer had actually assigned — not by forging a resolution.

### Technical

- Removing a mechanism beat extending it. The tie-breaking vocabulary was wired into one call site and carried a substring false positive; deleting it closed all six sites and removed the false-positive class outright. Less configuration, fewer paths, no vocabulary to drift.
- Content cannot distinguish a finding from prose. Three attempts to recognise a findings table by cell content each reddened a legitimate template section — `## Issues Encountered`, `## Autonomous Decisions`, a decoy note. Recognition belongs to structure and closed vocabularies.
- Measure before assuming a shape is legitimate: zero `[header, delimiter]`-only blocks exist across 57 artifacts and templates, which is what made the unconditional rule safe.
