## Summary

Every new DEFINE now carries a machine-readable `risk_profile` — level derived deterministically as max(5 dimensions) raised by data-declared elevation floors (auth→high, destructive migration→critical, …), with auditable overrides that can never remove the CRITICAL halt. `spec-lint --phase define` validates it via the new `DefinePhaseContract` in strict Observe/Warn mode: all 5 `RP.*` rules are WARN-only (exit 0), legacy DEFINEs default to a visible `medium` — never a silent `low` — and pre-existing FAIL semantics are preserved byte-for-byte. Design echoes the level; Build can carry it. This is Increment 2 / PR 2: the profile Increments 4–5 (risk-driven TDD, Task Review) will key their policies on. Delivered by the first full `/auto` autonomous run of the program (0 human pauses post-ignition).

## Lessons Learned

### Process

- The whole-branch adversarial review caught a genuine Observe/Warn violation the entire test suite missed (uniformly-`##` fixtures made the heading narrowing invisible) — reviews must probe *behavioral parity with the previous version*, not just the new feature's own ATs.
- An autonomous run's fix loop works: 1 Critical + 3 Minors found, fixed, and independently re-verified (reviewer re-ran its own repros) inside 1 of 2 budgeted rounds, with zero human pauses.

### Technical

- Precedent is not policy: Increment 1's "single ##-only heading vocabulary" was correct for a *newborn* contract (Build) but wrong for a phase with *pre-existing* FAIL behavior (Define) — preserving old semantics required a dual vocabulary (presence `#{1,6}` byte-identical to the old contract; new WARN-stakes scanning ##-only).
- YAML truthiness bites twice: quoted `"false"` is a truthy string — boolean-ish contract fields need strict `is True` / literal-"true" checks, mirroring Increment 1's quoted-`"off"` lesson.
- Rank comparisons between two YAML lists (levels vs dimension_values) need an explicit order-consistency guard at load time, or a future reorder silently corrupts every derivation check.

### Communication

- Recording the rollout mode (`rollout: observe_warn`) as contract data makes the Enforce flip a visible, versioned decision instead of a code change — reviewers and tests can anchor on it.

### Tools & Libraries

- The Gate J budget skip (spec-judge exit 3) demonstrated the visible-skip discipline end to end: coverage narrowed loudly in the ledger, nothing assumed.
