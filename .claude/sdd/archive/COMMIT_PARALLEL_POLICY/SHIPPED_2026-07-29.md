## Lessons Learned

### Process

- Gate L earned its budget: the Increment-6 TX rule caught a real matrix gap in this increment's own DESIGN on first lint — the first live REFINE of the program, proving the cross-increment compounding is real.
- Infrastructure outages test the policy spine: with the Agent tool down, the tempting move was self-review; the run waited and retried instead — an assumed verdict would have poisoned Gates R/S downstream.

### Technical

- Stale scope-deferral sentences are time bombs: Increment 3's "sequential until the scheduling increment lands" sat quietly until this increment contradicted it in the same file. Grep for deferral language when delivering the deferred thing.
- An honest `session` commit record beats retconned per-task history — the vocabulary exists precisely so reality can be recorded.
