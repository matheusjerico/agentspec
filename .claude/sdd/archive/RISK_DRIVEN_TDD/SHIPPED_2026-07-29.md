## Summary

TDD is now policy, not just a flag: the effective mode is derived as the strongest of the `--tdd` flag, the risk policy keyed on the DEFINE's `risk_profile.level` (high/critical → required — the §8.3 TDD matrix row activated), and any manifest task declaring `execution.tdd: required`. `--no-tdd` dispenses only low/medium with a recorded justification and is refused at high/critical. The BUILD_REPORT contract enforces the floor deterministically (`BR.tdd_required_by_risk`: high/critical+off FAIL, medium+off WARN, adoption paths silent) and validates sanctioned exceptions (`BR.tdd_exception_invalid` against 5 contract-data categories). RED-validity rules (§10.2) land as skill conduct. Increment 4 / PR 4 — third fully autonomous `/auto` run; this run's own report exercised the new medium+off WARN live on its own gate.

## Lessons Learned

### Process

- A fix can create the opposite failure mode: round 1 closed a false-positive (incidental "exception:" text) by overshooting into a false-negative that bypassed the DEFINE's own acceptance-test wording — caught only because the reviewer re-probed the FIX against the spec, not just the original bug. Fix rounds must re-read the requirements, not just the finding.
- Dogfooding the WARN path live (this report's own medium+off) proved the observe-side semantics end to end at zero cost — an honest `off` with a visible WARN beats fabricated evidence every time.

### Technical

- Grammar-anchored regexes need a boundary anchor, not a prefix token: cell-start (`^|\|`) with an optional template prefix satisfies both failure directions simultaneously.
- Enum-like contract values (risk_policy obligations) must be vocabulary-validated at load time — a capitalized typo would have silently disabled the exact fail-closed guarantee this feature ships (fourth YAML-strictness lesson of the program).
- Consistency sweeps matter on rewrites: renaming a section leaves stale anchors and flag-only framings in 3 other places of the same file; the review caught what the section-local edit missed.

### Tools & Libraries

- Optional constructor params with `None` defaults keep 100% of existing call sites valid — backward compatibility by construction across four consecutive contract extensions.
