## Summary

Defects are now caught per task, before dependents build on them: sdd-build gains Step 4.6 — after each task's verification, its manifest `reviewer` is dispatched **blind-first** (never seeing the implementer's rationale before the initial assessment), producing a task verdict (`clean` / `clean-with-minors` / `dirty` / `skipped-by-policy`) with a 1-round fix budget separate from the final review's 2; `dirty` blocks all dependents. The BUILD_REPORT gains the Task Reviews section, and the contract gate enforces it: missing reviews FAIL at high/critical report risk (WARN at medium, silent at low/legacy), any `dirty` verdict FAILs at every level. The whole-branch final review stays mandatory and byte-identical — diff-verified and pinned by test. Increment 5 / PR 5; fourth fully autonomous `/auto` run.

## Lessons Learned

### Process

- Bug classes recur across increments: the decoy-shadow hole fixed in Increment 3's design contract reappeared verbatim in this increment's new scan site — the reviewer caught it by consciously carrying the prior increment's Critical forward as an attack pattern. Reviews should replay the program's own past Criticals against every new surface.
- Scope discipline under an invariant: the same hole exists in pre-existing scans (tdd_evidence), but fixing it here would touch the final-review scoping this feature's own invariant froze — deferring with a named residual (and the `_section_exact` pattern ready) beat a silent drive-by.

### Technical

- Template-fixed headings should be matched by slug EQUALITY; prefix matching is only for headings the template itself varies. False-FAIL and false-PASS are two directions of one scoping bug — regression tests must pin both.
- Parallel parsers in one class must share their guards: the task parser had a placeholder brace-guard its sibling review parser lacked — symmetric code needs symmetric defenses.

### Communication

- A voluntary dogfood (Task Reviews rows on a medium-risk report where Warn tolerates absence) validated the shipped shape live at zero enforcement cost, with provenance honestly noted.
