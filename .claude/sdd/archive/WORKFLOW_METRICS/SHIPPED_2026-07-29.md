## Summary

Runs are now comparable without prose: every BUILD_REPORT carries a machine-readable `workflow_metrics` block (schema v1, closed 13-key catalog — durations, task count, effective parallelism, tests by type, fix rounds, findings by severity/stage, requirements coverage, operational skips, risk overrides, tokens/cost) validated by five new `BR.metrics_*` linter rules built TDD RED-first. The availability rule is the spine: an unmeasured value is `{value: null, reason}` — never estimated, interpolated, or copied — and the linter enforces it, down to rejecting a verbatim unfilled template copy (the review's Critical catch). Ship summarizes the block into SHIPPED's new Workflow Metrics subsection; the §15.3 boundary is written down — metrics never auto-change policies. Increment 9 / PR 9 — the final increment: the program closes with the measuring stick that lets the §22 benchmark repetition be judged mechanically.

## Lessons Learned

### Process

- The reviewer attacking the FIX is as valuable as attacking the feature: round 2 found my F5 fix had missed two more citations of the same phantom key in the same file — grep for the wrong fact repo-wide, not just where the reviewer pointed.
- A Critical in the rule that guards against fabrication (an unfilled template PASSing) is the exact failure the program exists to prevent — adversarial review with independent repros, not test-reading, is what caught it.

### Technical

- Guards must cover the template attack: any validator whose input has a template needs an unfilled-placeholder check — this file already had two (matrix rows, Overall line); the new rule initially forgot the third.
- Key-name sniffing is not shape awareness: `path.endswith("reason")` exempted `override_reason` — exemptions belong to validated shapes (the availability mapping), never to name patterns.
- str.replace edits fail silently: the version_history insert no-op'd once and left a mismatched header/body — exact-match Edit with existence assertion (or a pinning test, which now exists) is the only safe way.
